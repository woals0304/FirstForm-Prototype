## 네 이미지에서 추출한 공통 시각 원칙

1. **장소가 먼저 보이는 무협**: 산의 층, 대나무, 물길과 작은 건축물로 공간감을 만들고 그 안에 무인을 둡니다. 지도와 현재 활동 장면에 새로 작성한 SVG를 사용합니다.
2. **하나의 활동에 집중**: 캐릭터, 현재 활동, 진행, 최근 소식이 서로 가까이 있도록 구성합니다. 무인의 상태는 데스크톱의 왼쪽, 작은 화면의 위쪽에 위치합니다.
3. **장면과 정보의 구분**: 지도·활동은 풍경 영역, 선택·보상은 밝은 종이색 면에 배치합니다. 실제 전투의 체력 변화와 애니메이션이 계산 결과를 따릅니다.
4. **절제된 색의 역할**: 녹색은 활동과 선택, 종이색은 읽는 영역, 옅은 황토색은 단련, 붉은 갈색은 적 체력에 사용합니다. 어두운 남색 패널이나 금색 테두리를 가져오지 않았습니다.
5. **짧은 결과와 다음 방향**: 누적 보고에서 자원·격파·후퇴·개방을 확인하고 다시 지도나 무공 선택으로 이동합니다.

원본 이미지 파일을 새 폴더에 복사하거나 자르기·트레이싱·레이아웃 그대로 재현하지 않았습니다. 여러 이미지의 장소 중심 구성과 정보 계층을 해석했습니다.

## 기존 프로젝트에서 재사용한 요소

**파일·코드·에셋·저장·수치의 직접 재사용: 없음.** C# 코드, Unity 씬·프리팹·폰트·스프라이트·PlayerPrefs·저장 fixture를 복사하거나 읽어 들이지 않습니다. 참조 이미지도 앱의 에셋으로 포함하지 않습니다.

개념 참고는 다음과 같습니다.

- FirstForm 프로젝트명
- 회류보 명칭과 병기에 종속되지 않는 보법 개념 (효과·수치는 새 체험 규칙)
- 자동 활동, 부재 안전, 누적 결과 후 다음 방향을 고르는 흐름
- 무공·병기·적 전법 상호작용과 무공별 숙련
- 콘텐츠 정의와 상태·표현을 구분하는 작은 구조
