# 픽셀 게임 화면 개편

2026-09-06 · `codex/pixel-game-screen`

## 바꾼 표현

메인 화면 전체를 현재 지역의 풍경으로 채우고, 그 안에 무인을 배치했습니다. 웹사이트형 상단 메뉴, 고정 프로필 사이드바, 대시보드 카드 구성을 제거했습니다. 이름·체력·기초 경험과 보유 자원은 작은 HUD에, 최근 소식·강적 도전과 게임 메뉴는 화면 아래에 둡니다.

- 청죽림, 적운산채, 운무나루, 백운고개 각각 고유한 픽셀 배경.
- 기존 상태를 읽어 걷기 → 주변 탐색/채집 → 전투 → 운기 조식 자세로 표현. 걷기 4프레임, 병기별 타격 자세, 피격·피해 숫자·베기·회복 입자와 실제 적 수·개별 체력 표시.
- 강호는 별도 풍경 지도. 지역 표식을 선택하면 적 구성·보상·추천 이유와 개방 조건을 확인하고 직접 출발.
- 무공·병기·행로 기록은 필요할 때 여는 게임 창. 배경의 활동은 계속되며 Esc, 닫기, 창 바깥 클릭으로 돌아옵니다. 네이티브 dialog의 키보드 포커스 제한을 사용합니다.
- 한글 Galmuri 픽셀 글꼴, 사각 격자 아이콘, 종이색·이끼색 HUD와 단순한 테두리로 통일.
- 모바일 세로에서는 HUD와 메뉴를 재배치하고 지도 상세는 스크롤. 짧은 가로 화면도 현장과 메뉴가 한 화면에 들어옵니다. 작은 세로 화면에서는 카메라를 지면 쪽으로 당겨 캐릭터가 공중에 뜨지 않게 했습니다.
- 운영체제의 동작 줄이기 설정에서는 애니메이션을 끕니다.

## 유지한 것

`src/game.ts`와 `src/game.test.ts`는 개편 전과 바이트 단위로 동일합니다. 전투 수식·수치, 데이터 구조, 모든 콘텐츠, 추천, 성장, 보상, 강적·해금, 저장 키/형식/검증, 부재 정산 상한은 변경하지 않았습니다. 기존 App의 저장·시계 연결 코드는 `src/useGame.ts`로 분리했습니다.

4개 지역, 3개 무공, 3개 병기, 자동 활동·전투·휴식, 호흡 단련, 자유로운 지역 선택, 강적의 부재 중 정지, 보상 즉시 지급과 기록 확인, 1분 보내기, 일시정지, 기존 저장 이어하기가 그대로 작동합니다. 회귀·문파·성향·복잡한 강화·경지 체계·과금·새 진행 시스템을 추가하지 않았습니다.

Galmuri 2.40.3의 Galmuri11/굵은체를 로컬 번들로 제공합니다. [SIL OFL 라이선스](../public/art/Galmuri-OFL.md)를 포함했습니다. Unity 코드·폰트·씬·에셋·저장 데이터의 직접 재사용은 없습니다.

## 보류한 디자인

밝은 동양풍 픽셀 아트는 이번 요청에 맞춰 적용했습니다. 캐릭터 복식과 비례, 고유 적·강적 전용 외형, 최종 픽셀 해상도와 타일 규격, 더 풍부한 연결 동작은 임시입니다. 현재 16칸 아틀라스를 공유하며 적은 들개·늑대·산적·철갑 무인으로 묶어 표시합니다. 걷기·회복은 공통 여행 복장, 전투 자세는 장착 병기에 맞춥니다.

원본 전투 그림의 대응 버튼과 기존 자동 전투 설계의 차이는 자동 전투를 유지하는 것으로 잠정 처리했습니다. 원본의 세로 중심 비율 대신 이번 요청대로 반응형을 유지했습니다. 무공 계열 제한·강적 개입·경지 등 기존 조사에서 보류한 시스템 결정은 이번 표현 개편으로 확정하지 않았습니다.

## 실행·검증

```powershell
cd D:\projects\FirstForm-Prototype
npm.cmd run dev
# http://127.0.0.1:5173
```

빌드 후 미리보기는 `npm.cmd run build` → `npm.cmd run preview`, 기본 주소는 `http://127.0.0.1:4173`입니다.

- TypeScript 검사 및 Vite 프로덕션 빌드 통과.
- 기존 Vitest 테스트 21개 통과. 테스트 파일과 게임 로직 파일의 SHA256 동일.
- Chrome에서 기존 저장을 이어서 무공 변경, 병기 구매/장착, 호흡 단련, 강적 중 변경 금지, 모든 강적 격파·네 지역 해금, 보상 목표 변경, 자유 이동, 기록 확인, 일시정지·재개, 새로고침 저장 유지 확인.
- 기록 확인 전후 보유 보상 동일: 중복 지급 없음.
- 부재 60초의 실제 브라우저 정산 결과 60초 증가. 즉시 재접속 증가 0초: 중복 정산 없음.
- 이동·탐색·전투·회복 자세 확인. 전투·회복 캡처에는 기존 엔진의 simulate로 만든 상태를 사용했고, 검증 후 브라우저 진행을 복원했습니다. 생산 코드에 테스트 우회 API는 없습니다.
- 320×568, 320×640, 390×844, 768×1024, 844×390, 1280×720, 1920×1080에서 가로 넘침 없고 현장 메뉴가 화면 안에 들어오는지 확인. 1440×960에서 대표 화면 캡처. 모바일 세로/가로 지도 출발과 대화창 조작 확인.
- 6개 이미지 로딩 성공, 스프라이트 모서리 알파 0, 한글 픽셀 글꼴 로딩, reduced-motion에서 애니메이션 none 확인.
- 브라우저 콘솔 오류·경고 0건.
- 원본 Unity 추적 파일 893개 해시 비교: 변경 0개. 원래 존재하던 폰트 에셋의 수정 상태도 그대로 유지.
