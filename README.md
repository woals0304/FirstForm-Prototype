# FirstForm · 강호를 걷다

새 방치형 무협 RPG의 재미를 확인하기 위한 독립 React + TypeScript 시제품입니다. 원본 Unity 프로젝트 `D:/projects/FirstForm`은 읽기 전용 참고 자료이며, 이 앱은 Unity 코드·에셋·저장 데이터에 의존하지 않습니다.

## 실행

Node.js 22 환경에서 검증했습니다. PowerShell에서:

```powershell
cd D:\projects\FirstForm-Prototype
npm.cmd install
npm.cmd run dev
```

브라우저에서 <http://127.0.0.1:5173>을 엽니다. 이미 의존성이 설치되어 있으면 `npm.cmd run dev`만 실행하면 됩니다. 포트가 사용 중이면 Vite가 안내하는 주소를 확인하세요.

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

프로덕션 미리보기의 기본 주소는 <http://127.0.0.1:4173>입니다. 픽셀 이미지와 한글 Galmuri 글꼴은 로컬 파일로 제공됩니다. 설치 후 플레이에는 외부 서버가 필요하지 않습니다.

## 5분 체험 순서

1. 청죽림에서 자동 탐색·전투가 시작됩니다. 지도에서 다른 지역을 눌러 적과 보상, 개방 조건을 읽습니다.
2. 아래의 **체험 · 1분 보내기**를 1~2회 눌러 결과를 쌓습니다. 실제로 기다려도 같은 계산을 사용합니다.
3. 하단 **병기**에서 병기를 구입하고 **무공**에서 초식을 바꿉니다. 검은 정확도, 도는 무리 상대, 창은 철갑 관통에 강점이 있습니다.
4. 현장 화면에서 조우 4회 격파 후 **강적 도전**을 누릅니다. 자동 대결의 승리로 다음 지역이 개방됩니다. 실패하면 자원을 보존하고 휴식합니다.
5. **강호** 지도에서 지역과 **원하는 보상**을 바꿔 추천을 비교합니다. 추천과 다른 열린 지역에도 자유롭게 갈 수 있습니다.
6. **행로 기록**에서 시간·획득·격파·후퇴·새 길을 확인합니다. 보상은 이미 지급되어 있으며 기록 확인은 재지급 버튼이 아닙니다.

새 여정은 하단 **안내 → 새 여정 시작**에서 초기화 확인 후 시작할 수 있습니다.

## 구현 범위

- 무인 1명, 자동 탐색·채집·일반 전투·회복
- 독립 숙련을 가진 무공 3개: 청풍연식, 파암일격, 회류보
- 병기 3개: 청죽검, 환두도, 백목창
- 기초 단련 경험과 약초·깨달음을 소비하는 호흡 단련
- 청죽림 → 적운산채 → 운무나루 → 백운고개, 각 지역 강적 1명
- 적의 수·방어·회피·공격 간격과 보상 분포에 따른 차이
- 현재 병기·무공·숙련·성장·희망 보상을 고려하는 참고용 추천
- 실시간과 같은 고정 1초 시뮬레이션을 사용하는 부재 정산, 최대 8시간
- 브라우저 localStorage 하나에 독립 저장, 재정산 중복 방지, 손상 기록 보존 및 저장 실패 안내
- 320px부터 데스크톱까지 재배치되는 화면. 화면비 고정 없음

## 임시 규칙과 한계

- **현재 화면은 밝은 동양풍 픽셀 아트 시제품입니다.** 새로 생성한 지역 풍경 4장, 별도 강호 지도, 16칸 캐릭터 아틀라스와 한글 픽셀 글꼴을 사용합니다. 세부 복식·적별 고유 외형·최종 미술 제작 규격은 보류합니다.
- 강적은 직접 시작하고 전투 자체는 자동입니다. 부재 중 강적 대결은 동일 상태에서 멈춥니다. 패배하면 안전 후퇴하며 자원 손실은 없습니다.
- 강적 조우 조건(일반 조우 4회), 성장 속도, 상점 가격, 8시간 상한과 추천 가중치는 체험용 수치입니다.
- 세 무공과 세 병기를 자유롭게 조합합니다. 기존 설계의 전용 검법 요구 조건을 변경한 것이 아닙니다. 이름과 콘텐츠를 구분했으며 계열 제한의 최종 체계는 보류합니다.
- 반복 일반 전투는 접속하지 않아도 진행하지만, 서버 시간 검증·치트 방지·여러 탭 동기화·클라우드 저장·저장 이전은 없습니다. 한 탭에서 플레이하세요.
- 회귀, 문파, 성향, 복잡한 강화, 신병이기, 경지 단계 체계, 과금·출석·일일 임무는 없습니다.

## 파일 구성

- `src/game.ts`: 콘텐츠 정의, 순수 시뮬레이션, 추천과 작은 저장 검증
- `src/App.tsx`: 현장·강호 화면과 무공·병기·기록 게임 창
- `src/Art.tsx`: 픽셀 풍경 캔버스, 스프라이트·격자 아이콘·활동 효과
- `src/useGame.ts`: 기존 시계·부재 정산·브라우저 저장 연결
- `src/style.css`: 반응형 게임 HUD와 픽셀 UI
- `public/art/`: 새로 생성한 픽셀 에셋과 글꼴 라이선스
- `src/game.test.ts`: 전투·성장·해금·추천·저장 검증
